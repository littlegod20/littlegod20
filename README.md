### About

I'm Asante, a full-stack developer based in Accra, Ghana, with a backend-heavy focus and about 4+ years of experience. I build production systems, not demos. Recent work spans multi-tenant SaaS platforms, real-time mobile apps, and computer vision tooling, most of it shaped around problems specific to West African markets: local payment rails, low-bandwidth conditions, and informal commerce.

### Featured Projects

**[TuaKa](https://tuaka.org)** — Multi-tenant SaaS invoicing platform for West African SMBs, in production. Laravel 13, PostgreSQL, Redis/Horizon queues, with Paystack and MTN MoMo payment integration.

**Boame** — React Native service marketplace app with real-time chat over Socket.io, Paystack payments, and complete customer and provider booking flows.

**Motherboard** — React Native camera-based tool using the Claude Vision API to identify motherboard components, with a NestJS backend.

<details>
<summary>More on these projects</summary>
<br>

- TuaKa handles team management, subscription billing across free/Starter/Growth tiers, PDF generation, and scheduled jobs, all monitored with Sentry.
- Boame's real-time chat runs on a dedicated Socket context, with hierarchical React Query cache keys and Zustand-persisted auth across the app.
- Motherboard's core concept is a "dead board triage" mode for diagnosing non-functional boards, not just identifying components.

</details>
